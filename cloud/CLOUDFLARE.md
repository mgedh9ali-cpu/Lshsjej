# تشغيل اقتراحات «قوم دروس» عبر Cloudflare

هذه الحزمة مخصّصة لتطبيقَي «قوم دروس» 0.7.5. يستقبل Worker الاقتراحات ويحفظها في قاعدة D1 كي تظهر في لوحة المالك أونلاين. يدعم المسار نفسه نشر إشعارات المالك وردوده كما في التطبيق الحالي.

## الإعداد مرة واحدة

1. افتح مجلد الحزمة من جهاز التطوير وسجّل الدخول إلى Cloudflare عبر `npx wrangler login`.
2. نفّذ `npx wrangler d1 create qum-dorous`، وضع معرّف قاعدة البيانات الناتج مكان `REPLACE_WITH_D1_DATABASE_ID` في `wrangler.toml`.
3. نفّذ `npx wrangler d1 migrations apply DB --remote` ثم `npx wrangler deploy`. احتفظ بعنوان HTTPS الذي يظهر في نتيجة النشر.
4. ولّد قيمتين مستقلتين بالأمر `openssl rand -hex 32`. خزّن الأولى بالأمر `npx wrangler secret put QUM_OWNER_KEY` والثانية بالأمر `npx wrangler secret put QUM_STUDENT_KEY`. أدخل القيم عبر المطالبة التفاعلية.
5. افتح «الإعدادات ← الصف عبر الإنترنت» في كل تطبيق، واستخدم أصل عنوان HTTPS الناتج مثل `https://qum-dorous.example.workers.dev`. أدخل مفتاح المالك في لوحة المالك وشارك مفتاح الطالب فقط مع طلاب الصف.

يرسل الطالب اقتراحًا قصيرًا من «الاقتراحات». ثم يظهر النص في «صندوق الاقتراحات» في لوحة المالك. يمكن إرسال رد يظهر للطالب المعني. تبقى الاقتراحات محفوظة عند إغلاق لوحة المالك حتى يفتحها ويحدّث القائمة.
