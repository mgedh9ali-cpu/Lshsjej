# قوم دروس لأندرويد 0.7.6

يتصل تطبيق الطالب بخدمة «قوم دروس» تلقائيًا بعد تسجيل الاسم وكلمة السر على الهاتف. تُحفظ الاقتراحات المعلقة للإرسال عند عودة الإنترنت ما دام التطبيق مفتوحًا. تظهر الاقتراحات تلقائيًا في صندوق المالك أثناء فتحه.

على لوحة مالك جديدة، أدخل «مفتاح المالك» مرة واحدة في «الإعدادات ← اتصال لوحة المالك». يُحفظ المفتاح على الجهاز وتُستخدم الخدمة المضمّنة. تظل الإعدادات السابقة صالحة عند تحديث نسخة موقّعة بالشهادة نفسها.

توجد خدمة الإنتاج وإعدادات النشر على فرع `main`. يمكن استخدام ملفات `cloud/` في هذا الفرع للتطوير والاختبار المحلي.

## البناء والتحقق

يلزم Node.js 24 أو أحدث وJDK 17 وAndroid SDK بمنصة 36 وأدوات البناء 35.0.0. ضع خط ثمانية العادي والعريض في `android/fonts/` أو اضبط `SCHOOL_FONT_DIR`. فعّل `SCHOOL_REQUIRE_THMANYAH=1` للبناء الذي يشترط الخط. يستخدم بناء المعاينة Cairo عند غياب ملفات الخط.

اضبط `ANDROID_SDK_ROOT` و`JAVA_HOME` و`SCHOOL_KEYSTORE` و`SCHOOL_KEY_PASSWORD` ثم شغّل:

```sh
npm test
bash android/build.sh dist/QumDorous-Student.apk student
bash android/build.sh dist/QumDorous-Owner.apk owner
```

للترقية فوق تثبيت قائم يلزم استخدام شهادة التوقيع نفسها. اختبر تثبيت الحزمتين وتسجيل طالب من شبكة مختلفة عبر خادم HTTPS، ثم جرّب تسجيل الدخول بعد إعادة التشغيل ورفع صورة واستعادة نسخة احتياطية قبل التوزيع.
