# قوم دروس لأندرويد 0.8.1

يتصل تطبيق الطالب بخدمة «قوم دروس» تلقائيًا بعد تسجيل الاسم وكلمة السر على الهاتف. تُحفظ الاقتراحات المعلقة للإرسال عند عودة الإنترنت ما دام التطبيق مفتوحًا. تظهر الاقتراحات تلقائيًا في صندوق المالك أثناء فتحه.

لوحة المالك تتصل بالخدمة المضمّنة بعد اعتماد رمز الهاتف الظاهر في «الإعدادات ← اتصال لوحة المالك». يضيف مسؤول النشر الرمز إلى `QUM_OWNER_DEVICE_HASH` على الخدمة. يستمر اتصال الأجهزة التي حفظت اعتمادها السابق.

توجد خدمة الإنتاج وإعدادات النشر على فرع `main`. يمكن استخدام ملفات `cloud/` في هذا الفرع للتطوير والاختبار المحلي.

## البناء والتحقق

يلزم Node.js 24 أو أحدث وJDK 17 وAndroid SDK بمنصة 36 وأدوات البناء 35.0.0. ضع خط ثمانية العادي والعريض في `android/fonts/` أو اضبط `SCHOOL_FONT_DIR`. فعّل `SCHOOL_REQUIRE_THMANYAH=1` للبناء الذي يشترط الخط. يُستخدم Cairo عند غياب ملفات الخط. يتوقف بناء الإصدار إذا غاب مفتاح التوقيع الدائم.

احفظ نسخة مشفّرة من ملف التوقيع الدائم لتوقيع التحديثات المستقبلية. اضبط `ANDROID_SDK_ROOT` و`JAVA_HOME` و`SCHOOL_KEYSTORE` و`SCHOOL_KEY_PASSWORD` ثم شغّل:

```sh
npm test
bash android/build.sh dist/QumDorous-Student.apk student
bash android/build.sh dist/QumDorous-Owner.apk owner
```

للترقية فوق تثبيت قائم يلزم استخدام شهادة التوقيع نفسها. اختبر تثبيت الحزمتين وتسجيل طالب من شبكة مختلفة عبر خادم HTTPS، ثم جرّب تسجيل الدخول بعد إعادة التشغيل ورفع صورة واستعادة نسخة احتياطية قبل التوزيع.
