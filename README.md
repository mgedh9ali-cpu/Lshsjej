# قوم دروس لأندرويد 0.7.0

يتكوّن المشروع من تطبيق الطالب `school.dafaa` وتطبيق المالك `school.dafaa.owner`. افتح لوحة المالك وأنشئ الحسابات، ثم شارك رمز الصف من الإعدادات. في هاتف الطالب افتح «الإعدادات ← ربط حساب الصف» والصق الرمز. يحتاج محتوى الصف إلى شبكة واي فاي مشتركة وإبقاء تطبيق المالك متاحًا. تظل المصادر المحلية وقراءة الصور بالعربية والإنجليزية متاحة دون اتصال.

يحتفظ التطبيق برمز الجلسة بعد إغلاقه. تحتفظ لوحة المالك بقاعدة الصف في مساحة أندرويد الخاصة، وتوفر نسخة احتياطية مشفّرة بصيغة `.qdb` من الإعدادات. تحتوي النسخة على بيانات الصف، وتحفظ ملاحظات الطالب ومصادره المحلية على هاتفه.

## البناء والتحقق

يلزم Node.js 24 أو أحدث وJDK 17 وAndroid SDK بمنصة 36 وأدوات البناء 35.0.0. ضع خط ثمانية العادي والعريض في `android/fonts/` أو اضبط `SCHOOL_FONT_DIR`. فعّل `SCHOOL_REQUIRE_THMANYAH=1` للبناء الذي يشترط الخط. يستخدم بناء المعاينة Cairo عند غياب ملفات الخط.

اضبط `ANDROID_SDK_ROOT` و`JAVA_HOME` و`SCHOOL_KEYSTORE` و`SCHOOL_KEY_PASSWORD` ثم شغّل:

```sh
npm test
bash android/build.sh dist/QumDorous-Student.apk student
bash android/build.sh dist/QumDorous-Owner.apk owner
```

للترقية فوق تثبيت قائم يلزم استخدام شهادة التوقيع نفسها. اختبر تثبيت الحزمتين وربط هاتفين على الواي فاي، ثم جرّب تسجيل الدخول بعد إعادة التشغيل ورفع صورة واستعادة نسخة احتياطية قبل التوزيع.
